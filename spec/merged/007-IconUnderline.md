메뉴바 아이콘의 'A', '한' 글자 밑에 밑줄을 얇게 넣으려고 해.

# 사용자의 요청
- 아이콘이 너무 밋밋해서 'A', '한' 글자 아이콘 밑에 밑줄을 얇게 넣었으면 좋겠네
- 아이콘을 보면 공간적 여유는 충분히 있으니 지금 'A', '한'의 크기는 바꾸지 말고 아래에 밑줄을 넣어주는 걸로
- 밑줄 넣어도 별 문제 없어 보여
  - 'A' 높이 11.5pt: 여백 1pt + A + 여백 2pt + 밑줄 1pt + 여백 0.5pt → 16pt
  - '한' 높이 13.5pt: 여백 0pt + 한 + 여백 1pt + 밑줄 1pt + 여백 0.5pt → 16pt
- 제시한 숫자가 0.5가 있어서 넣은 거야.. 그냥 레티나 고려해서 작업하자. (32 x 32)
  - 'A' 높이 25pt: 여백 2pt + A + 여백 2pt + 밑줄 2pt + 여백 1pt → 32pt
  - '한' 높이 25pt: 여백 2pt + 한 + 여백 2pt + 밑줄 2pt + 여백 1pt → 32pt
- 레티나 아닌 것은 32x32 아이콘을 → 16x16으로 렌더링해서 만들어줘
- 밑줄 길이 28로 글자보다 크게 해줘
- 0.1.3으로 바꿔서 적용해줘

# 현재 파악된 상태
- STANDARD §2.3: 메뉴바 아이콘은 한글 모드 "한", 영어 모드 "A"이고 템플릿 이미지임. 밑줄은 없음
  - 005 적용 후(0.1.2) 다른 메뉴바 아이콘처럼 흰색으로 보임 (사용자 확인)
- 다른 메뉴바 아이콘보다 작아 보임 (사용자: 집중 모드 아이콘이 훨씬 크게 보임)
  - 아이콘 크기(16×16pt)는 macOS 기본 입력기(Tamil, Ainu)와 같음
  - 기본 입력기 아이콘은 16pt를 다 채운 둥근 사각형에 글자를 뚫은 모양. Tamil 아이콘의 뚫린 글자는 높이 9pt, 너비 10.5pt이고 위아래로 3.5pt씩 사각형이 있음. 글자는 우리보다 작지만 사각형이 16pt를 채워서 커 보임
  - 우리 아이콘은 글자만 있어서 'A'는 높이 10.5pt, '한'은 12.5pt만 차지함 (32×32에서 'A' 21픽셀, '한' 25픽셀)
- 아이콘은 resources/korean.tiff, resources/english.tiff. 파일마다 16×16(Retina가 아닌 화면용)과 32×32(Retina 화면용) 그림이 들어 있음
  - 원본 그림(PNG)이나 아이콘을 만드는 도구는 저장소에 없음
  - 글자 크기를 그대로 두면 지금 그림을 옮기고 밑줄만 더하면 됨. 글자를 키우려면 글꼴을 골라 새로 그려야 해서 글자 모양이 조금 달라질 수 있음
  - 지금 글자는 Apple SD Gothic Neo와 모양이 같음. 잉크 면적은 SemiBold가 가장 가까움 ('한' −1.7%, 'A' −6.7%)
- 글자 위아래에 비어 있는 줄 수 (픽셀)

| 글자 | 16×16 위 | 16×16 아래 | 32×32 위 | 32×32 아래 |
|---|---|---|---|---|
| 한 | 2 | 1 | 4 | 3 |
| A | 3 | 3 | 5 | 6 |

- 사용자 화면은 내장 Retina 디스플레이 하나라 32×32 그림이 쓰임
- 16×16 그림은 1픽셀이 1pt라서 0.5pt는 그릴 수 없음

# 명세서 수정 방향
- §2.3: 메뉴바 아이콘 "한", "A" 글자 밑에 밑줄을 둠
- §2.3: 32×32 그림의 세로 배치를 표로 적음. 두 아이콘이 같음: 위 여백 2, 글자 25, 간격 2, 밑줄 2, 아래 여백 1 (픽셀)
- §2.3: 밑줄 길이는 28픽셀로 글자보다 길고, 가운데에 둠
- §2.3: 16×16 그림은 32×32 그림을 줄여서 만듦
- §2.3: 아이콘은 저장소의 명령(cargo xtask)으로 그림
- 버전: STANDARD는 그대로. 적용할 때 Cargo.toml의 버전을 0.1.2에서 0.1.3으로 올림

# 논의사항
1. '한' 아래 여유가 부족한 것을 어떻게 할지
   - 글자를 그대로 두고 맨 아래에 밑줄: 1pt 밑줄이면 32×32에서는 글자와 0.5pt 띄울 수 있지만, 16×16에서는 'ㄴ'에 붙음
   - 글자 크기는 그대로 두고 '한'만 위로 1pt(16×16에서 1픽셀, 32×32에서 2픽셀) 올림: 두 크기 모두 밑줄과 띄울 수 있음
   - 결정: 사용자가 준 배치대로. 32×32에서 '한'을 2픽셀 올려 위 여백 2픽셀, 밑줄과 2픽셀 띄움
2. 밑줄 굵기: 1pt(16×16에서 1픽셀, 32×32에서 2픽셀)로 할지, 0.5pt로 할지 (0.5pt는 32×32에서만 가능)
   - 결정: 32×32에서 2픽셀 (1pt)
3. 밑줄의 길이와 높이: 두 아이콘을 같게 할지(모드를 바꿔도 밑줄은 그대로), 글자마다 폭과 바로 아래 위치에 맞출지
   - 높이 결정: 두 아이콘 같음 (32×32에서 아래 여백 1픽셀 바로 위)
   - 길이 결정: 28픽셀로 글자보다 길게. 두 아이콘 같고 가운데에 둠
4. 다른 메뉴바 아이콘보다 작아 보이는 것을 어떻게 할지
   - 그대로: 요청대로 글자 크기는 두고 밑줄만 넣음
   - 글자를 키움: 16pt 안을 더 채움
   - 기본 입력기처럼 16pt를 채운 둥근 사각형에 글자를 뚫음
   - 결정: 사용자가 준 배치대로 두 글자 모두 32×32에서 높이 25픽셀. '한'은 지금과 같고, 'A'는 21픽셀에서 25픽셀로 커짐
5. 16×16 그림 (0.5pt를 그릴 수 없음)
   - 결정: 32×32 그림을 16×16으로 줄여서 만듦
6. 아이콘을 그리는 코드를 저장소에 남길지 (지금은 원본도 도구도 없어서 다시 그리기 어려움)
   - 결정: 제안대로. cargo xtask 명령으로 남김
