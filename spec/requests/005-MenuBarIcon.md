메뉴바 아이콘 색깔을 흰색으로 하려고 해.

# 사용자의 요청
- 한글(한), 영어(A) 아이콘 모두 흰색으로 표시함

# 현재 파악된 상태
- STANDARD §2.3에는 메뉴바 아이콘의 글자("한", "A")만 있고 색은 없음
- 아이콘은 resources/korean.tiff, resources/english.tiff (16×16, 32×32). 투명 배경에 검은 글자
- Info.plist에 TISIconIsTemplate이 켜져 있음. 이 설정대로면 macOS가 메뉴바 배경에 맞춰 색을 바꿈 (어두우면 흰색, 밝으면 검정). 실제 화면에서는 확인하지 않음

# 명세서 수정 방향
- §2.3: 메뉴바 아이콘의 색을 정함 (논의사항 1에 따라)

# 논의사항
1. 밝은 메뉴바에서도 늘 흰색으로 할지, 다른 메뉴바 아이콘처럼 배경에 따라 바뀌게 할지
   - 늘 흰색: 템플릿을 끄고 흰 글자 아이콘으로 바꿈. 밝은 메뉴바에서는 잘 안 보이고 다른 아이콘과 색이 달라짐
   - 배경에 따라: 지금 설정이 이 방식. 어두운 메뉴바에서도 검게 보인다면 템플릿 설정이 적용되지 않는 문제
