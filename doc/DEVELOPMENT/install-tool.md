# 설치 툴

- 관련 요청: `spec/requests/000-Project.md`의 "# 설치"
- 관련 스펙: `spec/STANDARD.md` §2.3 (설치)
- 상태: 형태는 설치본으로 결정됨(2026-10-17). 세부 사항은 확인을 기다림.

## 요구사항

- 소스코드를 받아 빌드하는 방식이 아니라 별도의 설치본으로 설치함
- 설치할 때 손쉬운 사용 권한을 설정할지 사용자가 정함. 이 권한은 터미널에서 Return/Esc를 다시 보내는 기능에 쓰임(`terminal-commit-keys.md`).
- 가급적 제거도 가능하게 함 (우선순위 낮음)

## 제안: macOS 설치 패키지(.pkg)

### 설치

- .pkg를 더블클릭해서 설치함.
- 설치 화면에 "터미널 보정 (손쉬운 사용 권한 필요)" 선택 항목을 둠. 선택하면 설치가 끝날 때 권한 요청 창을 띄움.
- 설치 위치는 `/Library/Input Methods/`(모든 사용자)로 함.
  - 설치 패키지가 보통 쓰는 위치이고, 설치할 때 관리자 암호를 한 번 입력함.
  - 현재 스펙 초안은 `~/Library/Input Methods/`이므로 스펙에 적용할 때 바꿔야 함.
- 설치 후 처리는 입력기 실행 파일(Rust)의 보조 명령이 맡음. 패키지 안의 스크립트는 이 명령을 부르기만 함.
  - 입력 소스 등록
  - 실행 중인 이전 버전 종료
  - 권한 요청
- 처음 설치라 입력 소스 목록에 바로 보이지 않으면 로그아웃 후 다시 로그인하라고 안내함.

참고: 권한은 설치 프로그램이 아니라 입력기 앱에 부여돼야 함.

- 그래서 입력기 앱을 "권한 요청 모드"로 사용자 화면에서 한 번 실행해 요청 창을 띄움.
- 설치 스크립트는 관리자 권한으로 돌기 때문에, 사용자 세션에서 실행하도록 따로 처리해야 함.

### 제거

- macOS에는 .pkg를 지우는 기능이 없음. 그래서 제거용 패키지를 따로 만듦.
- 제거용 패키지를 더블클릭하면 다음을 함.
  - 입력 소스 해제
  - 앱 번들 삭제
  - 권한 기록 초기화

### 만들기

- 빌드 명령 하나로 설치본과 제거본을 만듦. Rust/cargo 기반으로 관리함.
- 패키지는 macOS 기본 도구인 `pkgbuild`와 `productbuild`로 만듦.

## 설치본을 내려받아 열 때 (Gatekeeper)

- 인터넷에서 받은 .pkg는 Apple 공증(notarization)을 받지 않았으면 macOS가 바로 열지 못하게 막음.

| 방식 | 비용 | 사용자 경험 |
|---|---|---|
| 서명 없는 설치본 | 무료 | 처음 열 때 "시스템 설정 > 개인정보 보호 및 보안"에서 "그래도 열기"를 눌러야 함 |
| Developer ID 서명과 공증 | 유료 Apple Developer Program 가입 필요 | 경고 없이 열림. 업데이트해도 손쉬운 사용 권한이 유지됨 |

- 자세한 내용: `code-signing.md`

## 확인이 필요한 질문

- 설치본 서명: 무료로 하고 처음 한 번 "그래도 열기"를 감수할지, 유료 개발자 계정으로 서명·공증할지
- 설치 위치: `/Library/Input Methods/`(모든 사용자, 관리자 암호 필요)로 해도 되는지

## 검토했다가 제외한 방식

- 소스를 받아 cargo로 설치하는 방식 (`cargo install`, `cargo run`): 소스 다운로드와 Rust 설치가 필요해서 제외함
